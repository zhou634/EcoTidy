Why EcoTidy

它解决什么问题

野外数据的通病是"格式杂、脏、算起来烦"：Excel 表头写法五花八门、缺失值和异常值混在一起、多样性指数要在多个表之间倒来倒去、出图还要另装一堆软件。EcoTidy 把这条链路做成一条固定流程。

1导入：什么格式都能读
csv / xlsx / txt 通吃，自动识别数据类型与列名。带单位的 树高（m）、英文的 TreeHeight 都认；认不出来会弹出列映射让你手工指定，不会卡死。
2清洗：按生态学规则判异常
不是简单的 3σ。缺失值按「同样方 → 同物种 → 整列」三级回退填补；结构性空白（灌木本来就没有胸径）绝不用其它物种的值顶替。每步改动都写进日志，可直接引到论文方法部分。
3计算：常用生态指标齐备
群落结构（密度／频度／优势度／重要值）、多样性（Shannon／Simpson／Pielou／Margalef）、环境时序统计、土壤指标、实验生态指标。
4出图：三套配色，含纯黑白
灰阶／彩色／纯黑白（靠底纹区分系列）三种方案，导出 PNG（300dpi 可投稿）与 SVG（矢量可无损放大）。黑白方案适合黑白打印与色觉障碍读者。
5导出：一次拿到全部成果
数据表、指标表、清洗日志、图表、分析报告一次性打包导出，报告里写明数据情况、清洗统计、指标含义与数据质量评价。
6中英文实时切换
界面可随时切换中英文，无需重启。报告正文跟随语言设置；数据列名始终保持中文，保证与你的原始数据对得上。

FAQ

常见问题

多数疑问在软件内的帮助面板（按 F1）里也有答案。

会修改我的原始数据文件吗？
不会。软件只读取原始文件，清洗与计算都在内存中进行。所有成果（清洗后的数据、指标表、图表、报告）都导出到新文件，原始文件保持原样。
需要联网吗？会上传数据吗？
完全离线运行：不联网、不上传任何数据、不需要账号。断网状态下全部功能可用，适合有数据保密要求的场景。
图表里的中文会不会变成方框？
不会。软件随包内置思源黑体（SIL OFL 许可），用绝对路径注册字体，不依赖目标机器装了什么字体，换电脑也一样正常显示。
我的列名跟要求的不一样，能识别吗？
大部分能。带单位的 树高（m）、胸径(cm)，英文的 TreeHeight、DBH 都能识别。实在认不出来会弹出列映射对话框，让你手工把原始列名对应到标准字段，不会卡住。
数据存在哪里？换电脑会丢吗？
历史任务与设置存在 %APPDATA%\EcoTidy，导出的成果默认在「我的文档\EcoTidy」。换电脑时把 %APPDATA%\EcoTidy 一起带走，历史任务就还在。若该目录不可写，软件会自动改存到别处并在界面顶部说明实际位置。
被安全软件拦截了怎么办？
打包工具（PyInstaller）生成的程序常被误报，属于普遍现象。把 EcoTidy 文件夹加入白名单即可。程序不含任何联网行为，可自行用抓包工具验证。
怀疑运行不正常，怎么自查？
在命令行运行 EcoTidy.exe --selftest，它会跑一遍完整流程（读数据 → 清洗 → 计算 → 绘图 → 导出 → 建界面），并把逐项结果写到 %APPDATA%\EcoTidy\temp\EcoTidy_自检结果.txt。

代码在 GitHub 上，采用 MIT 许可，可自由使用、修改、分发（含商业用途）。仓库里含 481 项自动化测试与打包说明。
