内置帮助内容目录说明（static/help/）
================================================================
用途：开发方案第五章 5.7。F1 或菜单栏「帮助」唤起帮助与术语速查面板
      （ui/widgets/help_panel.py），内容全部从本目录读取。

为什么帮助内容放文件而不是写死在代码里
----------------------------------------------------------------
1. 帮助文本改动频繁，写死在 Python 字符串里每次都要重新打包 EXE；
2. 放 static/help/ 后可随包分发，必要时用户或实施人员能直接替换文本；
3. 页面右上角「?」按钮需要按页跳转到对应章节，用文件分节比代码分支清晰。

阶段 0 只建立目录本身。以下内容在后续阶段写入：
----------------------------------------------------------------
阶段 1：写入帮助面板所需的基础章节骨架（快速上手三步走、数据准备要求、常见问题）
阶段 4：写入术语速查表（香农指数、Simpson 指数、Pielou 均匀度、Margalef 丰富度、
        重要值、相对密度/频度/优势度、MAD 稳健统计、Olson 分解模型等，
        每条含"中文全称 + 公式 + 一句通俗解释"，与指标列悬浮提示共用同一份文案来源）
阶段 5：写入"图表中文显示方框怎么办"
阶段 9：写入 release/使用说明.txt 对应的离线版手册

帮助面板必须覆盖的四个板块（方案 5.7 节原文要求）
----------------------------------------------------------------
1. 快速上手三步走
2. 数据准备要求：样方群落 / 传感器时序 / 普通实验统计 三类数据分别需要哪些列
3. 术语速查表
4. 常见问题：中文乱码怎么办、列名识别不出来怎么办、图表中文显示方框怎么办
