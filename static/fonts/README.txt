中文字体目录（阶段 5 起必需）
================================================================

本目录存放随软件一起分发的开源中文字体，解决 matplotlib 出图时中文标题与坐标轴
标签显示成"方框"的问题（开发方案 第五章 5.7、第九章 避坑 10）。

当前已放入的字体
----------------------------------------------------------------
  NotoSansSC-Regular.ttf   —— 思源黑体简体中文（Noto Sans SC）
                              许可：SIL Open Font License 1.1（OFL）
                              来源：Google Noto 官方字形文件（NotoSansSC 可变字重版本）
                              大小：约 16.9 MB

OFL 1.1 允许随软件一起分发（包括商业分发），只需保留许可声明，因此可以放进交付 zip。

为什么不把文件名写死在代码里
----------------------------------------------------------------
core/plot_draw.py 按 *.otf → *.ttf → *.ttc 的顺序自动挑选本目录中的第一个字体文件，
并统一用 FontProperties(fname=绝对路径) 方式注册。换字体时只要替换文件即可，不必改代码。

为什么必须随包字体，而不是依赖系统字体
----------------------------------------------------------------
1. 打包成 EXE 后在干净 Windows 环境运行，无法假设目标机器装了哪款中文字体；
2. 用 FontProperties(fname=...) 直接指定字体文件，结果在任何机器上都一致；
3. 仅靠 rcParams["font.sans-serif"] 的字体名列表，在缺少这些字体的机器上会静默回退成方框。

换字体或增补字体的做法
----------------------------------------------------------------
1. 从官方地址下载 OFL 许可的中文字体：
   · Noto Sans SC     https://fonts.google.com/noto/specimen/Noto+Sans+SC
   · 思源黑体 Source Han Sans https://github.com/adobe-fonts/source-han-sans/releases
   · 思源宋体 Source Han Serif https://github.com/adobe-fonts/source-han-serif/releases
2. 把字体文件（.otf / .ttf / .ttc）放进本目录，删除旧文件即可，无需改代码。

许可提示（重要）
----------------------------------------------------------------
请只放入 OFL / Apache 等允许再分发的开源字体。
不要把 Windows 自带的 msyh.ttc（微软雅黑）、simhei.ttf（黑体）、simsun.ttc（宋体）
复制进本目录：这类字体的授权不允许随第三方软件再分发，交付 zip 时会构成许可问题。

若忘记放入字体会怎样
----------------------------------------------------------------
core/plot_draw.py 会退而使用系统里已安装的中文字体（例如微软雅黑），
图表仍能正常显示中文，但会在"绘图说明"里提示"当前使用系统字体，换一台电脑可能显示为方框"，
提醒你在发布前把字体放进本目录。
