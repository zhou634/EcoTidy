static/icons/ 目录说明
================================================================

用途
    存放界面用的图形资源。

当前状态：**目录为空是正常的，不是漏了文件。**
    界面图标（空状态大图标、应用图标）目前全部由代码用 QPainter 直接绘制，
    见 ui/widgets/icons.py 与 ui/main_window.py 的 build_app_icon()。

为什么用代码画而不是放图片（实测结论）
    1. 界面是"白色单色调 + 直角"风格，Emoji 由系统 Emoji 字体渲染，
       是**彩色**的（黄色文件夹、彩色折线），与整体风格冲突；
       而且不同 Windows 版本渲染差异很大，个别环境根本没有该字形。
    2. 代码画出来的图标是指令而非位图，任意尺寸都清晰，
       不需要为高分屏准备 @2x / @3x 多套文件。
    3. 不依赖字体是否安装。开发机上实测 QFontDatabase.families() 返回 0 个字体，
       用 drawText 画出来的图标只有一块空白，因此应用图标也是用矩形拼的。

什么时候才需要往这里放文件
    · 将来要换成第三方设计好的图标（.svg / .png）时；
    · 需要多套主题图标时。

注意
    · 本目录属于随包只读资源，路径常量见 utils/paths.py 的 ICONS_DIR。
    · 打包（PyInstaller）时必须把 static/ 整个目录带上，否则示例数据、
      中文字体、帮助内容都会缺失；具体命令见 release/打包说明.md。
